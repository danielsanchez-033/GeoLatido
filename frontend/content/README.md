# Contenido de la interfaz

Textos largos de Faro, en español (`es/`) e inglés (`en/`) con los mismos archivos e identificadores.

| Archivo | Uso |
|---|---|
| `radar.md` | Explicación breve de cómo ve el radar (RF-FAR-07) |
| `glossary.md` | Glosario. Cada término tiene un `id` estable (`<a id="...">`) para enlazarlo desde la tarjeta, el mapa o una ayuda emergente |

Los `id` de los estados y causas coinciden con los valores de la API (`change_probable`, `not_observable`…). Si la API añade o cambia uno, se actualiza aquí en los dos idiomas.
